# Installation d’un script dans Maya

*Dans ce document vous trouverez comment installer un script dans Maya et faire un raccourci pour l’utiliser avec facilité. Ce tutoriel comprend que l’utilisateur utilise Maya avec une interface en anglais.*

## Préparation
1. Télécharger l'[icône](https://github.com/AnnaButova/NAND403_A26_Ateliers/tree/main/atelier_8)

2. Créer un dossier sur le **Bureau/Desktop** de votre ordinateur
3. Nommer le dossier “icons” et y déposer le fichier de l'icône nouvellement téléchargé

## Installer le script dans Maya
1. Ouvrir **Maya**

2. Ouvrir un projet ou créer un nouveau projet au besoin
3. En haut, à gauche des shelves, repérer et appuyer le petit icône d’engrenage
4. Choisir **New Shelf** et le nommer
5. Dans les menu en haut aller dans **Windows > General Editors > Script Editor**
6. Ouvrir le fichier **atelier_8.py** sur [GitHub](https://github.com/AnnaButova/NAND403_A26_Ateliers/tree/main/atelier_8) 
7. Sélectionner et copier tout le code du fichier
8. Dans Script Editor, dans la fenêtre inférieure ouvrir le signet **Python** et y coller le code copié

## Faire un raccourci dans le shelf
1. Sélectionner tout le code dans le **Script Editor**, puis en maintenant le clic gauche, glisser le code dans l’espace du shelf nouvellement créé

2. Un pop-up va apparaître. Choisir **Python**

*Bravo! Vous avez maintenant un raccourci dans votre shelf de Maya, temps de le customiser avec une icône!*

3. Faire un clic droit sur l'icône de python que vous avez créé dans votre shelf et choisir **Open**

4. Si votre shelf n’est pas sélectionné automatiquement, cliquer sur le nom de votre shelf dans la liste des shelf à gauche
5. Dans les paramètres en bas, repérer **Icon Name** et cliquer sur l'icône du dossier
6. À gauche dans le menu **Folder Bookmarks**, trouver votre dossier “icons” et sélectionner le fichier icone.png, cliquer sur le bouton **Open**
7. Vous êtes de retour au menu **Shelves**, cliquer sur le bouton **Close**

***Félicitations, vous avez créé votre raccourci!***
